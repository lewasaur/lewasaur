## 🚀 Featured Projects

### 🎲 [D&D Combat Simulator](https://github.com/lewasaur/simplified-dnd-monte-carlo-combat-simulator)

A Python-based combat simulator that uses Monte Carlo simulation to estimate combat outcomes between D&D characters and creatures.

The project runs thousands of simulated encounters to estimate win probabilities and explore how differences in attributes such as AC, HP, attack bonuses, damage, and initiative affect combat outcomes.

**Python | Monte Carlo Simulation | Probability | Data Visualization**

### 📈 [Walmart Sales Forecasting](https://github.com/lewasaur/walmart-sales-forecasting)

A time series forecasting project using historical Walmart weekly sales data.

The project explores sales patterns across stores and uses Holt-Winters Exponential Smoothing to model seasonality and generate future weekly sales forecasts.

**Python | Pandas | Statsmodels | Time Series Forecasting | Matplotlib**
